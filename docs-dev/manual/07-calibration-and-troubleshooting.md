## 1. 原点（ホーム位置）の調整

### 1-1. 正しい状態

電源を入れた直後、ファームウェアは次の姿勢にサーボを動かします。

```cpp
servo1Langle = 120;  servo1.write(120);   // 肩 B (D10)
servo2Langle = 60;   servo2.write(60);    // 肩 C (D11)
servoup.write(10);                         // ペン上げ
```

この姿勢が **座標 (X=0, Y=0)**（＝肩の中点から 30 mm 上）に対応します。
このとき **左右の上腕（短いリンク）が水平** になっているのが正解です。

### 1-2. ずれている場合の直し方（順に試す）

#### ① ホーンを 1 コマずらす（まずこれ）

MG90S のホーンは 20 歯なので、1 コマ = 18 度です。粗い調整しかできません。

1. 通電してサーボが静止するのを待つ
2. 電源を切る
3. 上腕リンクごとホーンを抜き、**より水平に近いコマ** に差し直す

#### ② `initialangle` を書き換える（細かい調整）

`firmware/Drawing/Drawing.ino`（または公式版）の

```cpp
float initialangle = 60;
```

を数度ずつ変えて書き込み直します。

- **両方の腕が同じ向きに傾いている** 場合はここを調整します。
- 例: 全体が右に寄る → `58` や `62` を試す

#### ③ 左右で別々にずれている場合

`initialangle` は左右共通なので、片側だけずらすにはコードを分ける必要があります。

```cpp
// loop() の中
S1Totangle = S1Totangle - initialangle1;              // 例: 60
S2Totangle = 180 - (S2Totangle - initialangle2);      // 例: 62
```

のように 2 つの定数に分けてください。

### 1-3. 寸法の校正

描いた図形が **拡大／縮小して見える**、**縦横比がおかしい** 場合は、リンク寸法の実測値と
コード内の値がずれています。ノギスで **回転中心どうしの距離** を測って書き換えてください。

```cpp
float baselen = 4.5;   // 肩の回転中心どうしの距離 [cm]
float arm1len = 3.0;   // 上腕（肩の回転中心 → 肘の回転中心）
float arm2len = 6.0;   // 前腕（肘の回転中心 → ペン先）
```

> **測るのは「穴の中心から中心まで」** です。板の端から端ではありません。

## 2. ペン圧の調整

ペン先の押し付けはサーボではなく **引張バネ**（手順④）が担当しています。

| 症状 | 対処 |
|---|---|
| 線がかすれる／描けない | バネの張りを強める（バネの掛け位置を遠い穴へ）／ペンを少し深く挿す |
| 紙が破れる／ペン先が潰れる | バネを弱める／ペンを浅く挿す |
| 移動中にペンが紙を擦る | ペン上げ角度が足りない。`servoup` の上げ側の値（`10`）を調整する |
| ペンが上がりきらない／唸る | ペンサーボのホーン取り付け角がずれている。手順⑫からやり直す |

ペン昇降の角度はここで定義されています（`penupdown()`）。

```cpp
if (penpos == 1) { for (pos = 10;  pos <= 110; pos += 1) servoup.write(pos); }  // 下げ
else             { for (pos = 110; pos >  10;  pos -= 1) servoup.write(pos); }  // 上げ
```

`10`（上げ）と `110`（下げ）を変えれば昇降量を変えられます。
**両方の値を必ずセットで書き換えてください**（片方だけ変えると往復しなくなります）。

## 3. 症状別トラブルシューティング

### 3-1. 電源・書き込み系

| 症状 | 原因 | 対処 |
|---|---|---|
| 書き込みで `programmer is not responding` | HC-06 が D0/D1 を占有 | **HC-06 の TXD/RXD を抜く**（[03](03-wiring.md)） |
| 同上 | ブートローダの種類違い | ツール → プロセッサ → `ATmega328P (Old Bootloader)` |
| シリアルポートが出ない | CH340 ドライバ未導入 | CH340/CH341 ドライバをインストール |
| 通電してもサーボが動かない | ファーム未書き込み | [04](04-firmware.md) を実施 |
| 描画中に勝手に再起動する | サーボ 3 個の突入電流で 5V が落ちる | USB ポートを変える／電流に余裕のある電源を使う |

### 3-2. Bluetooth 系

| 症状 | 原因 | 対処 |
|---|---|---|
| アプリの一覧に `HC-06` が出ない | OS でペアリングしていない | 設定 → Bluetooth で `HC-06`（PIN `1234`）をペアリング |
| `Connection problem` が出る | 権限不足 / 他端末が接続中 | Android 12+ は「近くのデバイス」を許可。他の端末の接続を切る |
| 接続はできるが動かない | TXD/RXD の結線が逆 | HC-06 TXD → **D0**、RXD → **D1**（クロス） |
| 数点で止まる | `N` の応答が届いていない | D1(TX) → HC-06 RXD の線を確認 |
| HC-06 の LED | 点滅＝未接続 / 点灯＝接続中 | 判断材料に使えます |

### 3-3. 描画品質

| 症状 | 原因 | 対処 |
|---|---|---|
| 図形が **左右反転** する | 肩サーボ B / C の配線が入れ替わっている | **D10 と D11 のサーボを入れ替える** |
| 図形が歪む・平行四辺形になる | ホーンの取り付け角ずれ | 手順⑫ をやり直す（本ページ 1-2） |
| 図形が拡大／縮小する | リンク寸法とコードの不一致 | `baselen` / `arm1len` / `arm2len` を実測値に（本ページ 1-3） |
| 線が波打つ・ガタつく | 速度が速すぎる／関節のガタ | `msdelay` を大きくする／関節のネジを締め直す |
| 一部が描かれない | 描画範囲外の座標 | [06](06-serial-protocol.md) の範囲図を参照。範囲内に収める |
| 端の方だけ描かれない | 同上（ドーム型の外周） | Y を 20〜200 の範囲に収める |
| アームがガタつく | ベアリング外輪まで締めている | 手順⑦ を確認。外輪が自由に回るように |

### 3-4. 「一部が描かれない」の見分け方

ファームウェアは、到達できない座標が来ると **ペンを上げて何もせず `N` を返します**。

```cpp
if (S1Totangle >= 0 and S1Totangle <= 180) { ... } // 範囲内なら描く
else { if (penpos == 1) { penpos = 0; penupdown(); } }  // 範囲外はペンを上げるだけ
```

そのため「アプリ上では線が引けているのに、実機では途中で描かれない」ときは、
**故障ではなく範囲外** の可能性が高いです。次のコマンドで確認できます。

```bash
python3 tools/workspace_map.py --check <X> <Y>
```

## 4. 動作確認の手順（切り分け用）

配線・ファーム・アプリのどこが悪いかを切り分けるときの順番です。

1. **HC-06 を外し、Mini-USB で PC に接続**
2. Arduino IDE のシリアルモニタを **9600 baud / 改行なし** で開く
3. `0,0,0,R` を送る → `N` が返れば **ファームは正常**
4. `0,205,1,R` を送る → アームが動きペンが下りれば **配線とメカは正常**
5. ここまで OK なら、残りの問題は **Bluetooth かアプリ側** です

## 5. メンテナンス

- **サーボホーンのビスは緩みます。** 定期的に締め直してください。
- 関節のネジは「回るけどガタがない」程度が理想です。緩み止め剤は塗らないでください（分解できなくなります）。
- 長時間サーボに負荷がかかったまま放置すると発熱します。使わないときは電源を抜いてください。
- ペンを付けたまま保管すると、バネでペン先が押し付けられ続けます。外して保管するのが無難です。
