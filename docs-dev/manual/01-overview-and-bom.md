## 1. この機械の仕組み

このプロッターは **5 節平行リンク（five-bar linkage）** 方式です。

```
        ペン先 (selx, sely)
           ●
          / \
   前腕 60mm  60mm 前腕
        /       \
       ●         ●   ← 肘（自由回転、ベアリング）
       |         |
  上腕 30mm    30mm 上腕
       |         |
       ●─────────●   ← 肩（サーボ出力軸）
      B   45mm    C
   (D10)        (D11)
```

- 左右の肩に付いた **サーボ B / C** が、それぞれ上腕（30 mm）を回します。
- 上腕の先は肘で前腕（60 mm）につながり、2 本の前腕の交点がペン先になります。
- 2 つの肩の角度の組み合わせでペン先の XY 位置が決まります（ベルトもネジ軸も使いません）。
- 3 個目の **サーボ A** が、バネで押さえられたペンホルダーを持ち上げ／下ろします。

ファームウェアは、アプリから送られてきた XY 座標を **逆運動学（余弦定理）** でサーボ角度に変換します。
計算の中身は [04-firmware.md](04-firmware.md)、座標系と描画範囲は [06-serial-protocol.md](06-serial-protocol.md) を参照してください。

> **根拠**: 寸法は付属ファームウェア `Drawing.ino` の
> `baselen=4.5` / `arm1len=3.0` / `arm2len=6.0`（単位 cm）に一致します。

## 2. 主要部品

| 部品 | 型番・仕様 | 数量 | 備考 |

| 引張バネ | 5 × 0.4 × 6 | 1 | ペンを紙に押し付ける |

## 5. 必要工具・別途用意するもの

| もの | 用途 | 補足 |
|---|---|---|
| 六角レンチ（1.5 / 2.0 / 2.5 mm） | キャップボルト | 付属することが多い |
| 精密ドライバ（+） | M2 / M2.5 ビス | |
| Mini-USB ケーブル | ファームウェア書き込み・給電 | **Micro-USB ではありません** |
| PC（Arduino IDE） | ファームウェア書き込み | [04](04-firmware.md) |
| Android スマートフォン | 操作アプリ | **iPhone は不可**（[05](05-android-app.md)） |
| ペン | 描画 | ホルダー内径に入る細軸のもの。ボールペン／0.5 mm シャープ等 |
| ラジオペンチ | ナットの押さえ | 狭所でナットが回りやすい |

## 6. 組み立て前のチェック

- [ ] サーボ 3 個ともホーン（サーボアーム）とビスの小袋が揃っているか
- [ ] ベアリング 2 個が揃っているか（無いと肘がガタつきます）
- [ ] Mini-USB ケーブルがあるか
- [ ] **サーボホーンは手順⑫まで取り付けない**（先に付けると原点が狂います）
