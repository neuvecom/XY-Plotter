### 実施内容

リポジトリを Public に変更したことを受け、次の 2 点に対応した。

1. **メーカー付属資料（`official-manual/`）をリポジトリから削除**
   組立説明書 PDF・APK・操作動画はいずれもメーカーの著作物であり、

   公開状態での再配布は避けるべきものだった。

2. **コミットのメールアドレスを除去**
   `yoshiharu.sato@supership.jp` および `neuvecom@gmail.com` が
   コミットの author / committer として公開状態になっていたため、
   GitHub の noreply アドレスに置き換えた。

いずれもファイルを消すだけでは `.git` に残り、Public 化後も SHA 指定で取得できてしまうため、
**履歴を作り直して force push** する形をとった。

## 追記: 図版を SVG 線画で自作

付属写真をリポジトリから外したことで図が無くなったため、SVG の線画を新規に作成した。

### 方針

- **写真の再現は行わない。** 記憶で「それらしい組立写真」を描くと、ネジ本数や部品形状が
  誤った図になり、AI 生成画像と同じ問題を起こす。
- 代わりに **数値の裏が取れているもの** だけを図にした。
  - 機構図・座標系: ファームウェアの定数（baselen / arm1len / arm2len / divby / initialangle）から作図
  - 描画範囲: `tools/workspace_map.py` の逆運動学を呼んで到達可能領域を実際に計算し、その輪郭を描画
  - 配線図: `attach()` のピン番号と公式配線図の突き合わせ結果
  - 組立 16 ステップ: 「使う部品と数量」の早見表（部品カード）。配置や向きは付属 PDF に委ねる

### 変更

| ファイル | 内容 |
|---|---|
| `tools/diagrams/common.py` | SVG ビルダと部品アイコン（ボルト・ナット・ベアリング・バネ・サーボ等） |
| `tools/diagrams/mechanism.py` | 機構図 5 種を生成 |
| `tools/diagrams/steps.py` | 組立 16 ステップの部品カードを生成 |
| `docs-dev/manual/images/*.svg` | 生成物 21 点（機構図 5 + ステップ 16） |

ドキュメント側では、01 の ASCII リンク図と 06 の ASCII 座標図・ASCII 範囲マップを
SVG に置き換えて重複を解消した。

### 検証

- 5 種の機構図と 16 枚の部品カードを PNG にレンダリングして目視確認し、
  文字・線・注記の重なりを修正（配線の引き回し座標の誤り、軸の目盛が矢印より外に出る、
  数量の二重表示、注記ボックスの衝突など）。
- Markdown のリンクと画像参照を全走査し、リンク切れ 0 件を確認。
- SVG は合計 180KB 程度。外部フォント・外部参照なしで、GitHub 上でそのまま表示できる。

### 残課題

- 部品カードのアイコンは実物の形状を模した簡略図であり、寸法どおりではない。
- ペン昇降機構図のバネの掛け位置は個体差がある可能性があるため、図中に注記を入れた。
- 実物写真が必要な工程（板金の向き、ケーブルの取り回し）は付属 PDF のページ番号で誘導している。
